CDM (Casanova Drift Model) — Deep Dive

What it is

A mechanistic spray-drift simulator (v1.2.0) that models the complete physics of pesticide spray droplet transport from nozzle to ground. Originally developed by Ed Casanova (Bayer) and implemented in C++ by John Buonagurio (Exponent). Licensed AGPL-3.0.

Architecture (C++ modules)

Module File Role
Public API CDM.h C-linkage interface: create model from JSON, run, get output
Orchestrator CDM.cpp Ties all modules together in sequence
Atmospheric AtmosphericProperties.cpp Wet air density, viscosity, dew/wet-bulb temp (Antoine + psychrometric eqns)
Wind Profile WindVelocityProfile.cpp Logarithmic wind profile fitting, friction velocity, Richardson stability

Deposition Deposition.cpp Volume distribution → spatial deposition profile
DSD Model DropletSizeModel.cpp Non-linear least squares fit of droplet size distribution
Serialization Serialization.cpp JSON ↔︎ Model struct (nlohmann-json)
CLI CDMCLI.cpp Command-line driver

Physics Model (6-DOF ODE per droplet)

The state vector for each droplet has 6 components: [Z, X, Vz, Vx, Mw, Vvwx] - Gravity + buoyancy — net downward force accounting for air density - Aerodynamic drag — Clift & Gauvin correlation: CD = 24/Re * (1 + 0.197Re^0.63 + 0.00026Re^1.38) - Droplet evaporation — Ranz-Marshall mass transfer, driven by wet-bulb temperature depression (ΔTwb) - Wind interaction — log-law wind profile u(z) = (Uf/κ) * ln((z-hC)/z₀), coupled to droplet motion - Plume spreading — horizontal wind variation (ψψψ) expands the drift footprint crosswind The ODE is integrated by SUNDIALS CVODE (BDF method, 10000 output steps) until the droplet reaches ground (Z ≤ z₀ + hC) or time runs out.

Input/Output

Input: A JSON file specifying: - Droplet size distribution (cumulative volume fractions) - Atmosphere: temperature, pressure, humidity - Wind: velocity measurements at heights, horizontal variation - Nozzle: height, pressure, angle, solution properties - Field geometry: depth, width, nozzle spacing, application rate

Output: Deposition curve as [distance (m), % IAR] pairs — how much of the intended application rate lands at each downwind distance. New optional output: vertical drift profiles (% IAR per height bin at specified distances) for NTA/NTTP risk assessment.

Dependencies (vcpkg.json)

  • SUNDIALS — CVODE ODE solver
  • Ceres — non-linear least squares (DSD curve fitting)
  • Blaze — matrix math (deposition calculation)
  • Boost.Math — root finding, regression, constants
  • nlohmann-json — JSON parsing
  • fmt — formatted output

R Package (R/cdm/)

A thin wrapper: the R function cdm(config) calls the C API via .Call(’_cdm’, …), returning parsed JSON output as an R list. Includes demo scripts for the 3 SETAC DRAW test cases.

Sensitivity Analysis (sensitivity/)

A Python script (run_sensitivity.py) that:

  1. OAT (one-at-a-time) — perturbs 8 parameters (wind speed, nozzle height/pressure/angle, temperature, humidity, canopy height, wind direction variation) and measures deposition change
  2. Parameter sweeps — 15-point response curves for the top 4 most sensitive parameters
  3. Two-factor interactions — 8×8 heatmaps for wind×humidity and height×wind
  4. Outputs tornado diagrams, response curves, and interaction heatmaps. Calls cdmcli.exe via subprocess.

Vertical Profile Extension (recent work)

A new capability to extract vertical drift concentration profiles at specified downwind distances — critical for risk assessment of non-target arthropods and terrestrial plants at different canopy heights. Outputs % IAR per height bin (configurable bin width and max height)
